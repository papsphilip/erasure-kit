# ErasureKit

Free, open-source GDPR Article 17 data erasure tool.

## Quick Start

1. Open `erasure-kit.html` in any modern browser (Chrome, Firefox, Edge, Safari)
2. Enter your name and email addresses you want erased
3. Select data brokers from the built-in database
4. Send erasure requests with one click
5. Track responses and enforce 30-day GDPR deadlines

## Files

- `erasure-kit.html` -- The complete application (open this file)
- `brokers.json` -- Data broker database (can be updated independently)
- `README.md` -- This file

## Updating the Broker Database

The `brokers.json` file contains all known data brokers. You can:
- Edit it with any text editor to add or remove brokers
- Download the latest version from the GitHub repository
- Share your additions with the community via pull requests

## Privacy

- No data leaves your browser
- No accounts required
- No tracking or analytics
- All processing happens locally on your device
