Then create `src/lib/campaign.js` implementing:

**Constants:**
- `STORAGE_KEY = 'ek-campaign'`
- `CURRENT_VERSION = 1`

**`createEmptyCampaign()` function** (per D-09, D-10):
Returns the canonical campaign schema:
```javascript
{
  version: CURRENT_VERSION,
  createdAt: new Date().toISOString(),
  updatedAt: new Date().toISOString(),
  identity: { fullName: '', emails: [''], phone: '', address: '' },
  brokers: {},
  tempEmail: null,
  messages: [],
  statuses: {},
  settings: {},
}
```

**`migrateCampaign(data)` function** (per D-12):
- If `data` is null, not an object, or has no `version` property: return `null`
- If `data.version > CURRENT_VERSION`: return `null`
- Otherwise: merge with empty campaign template using spread: `{ ...empty, ...data, identity: { ...empty.identity, ...(data.identity || {}) }, updatedAt: new Date().toISOString(), version: CURRENT_VERSION }`

**`loadFromStorage()` function:**
- Try `localStorage.getItem(STORAGE_KEY)`, parse JSON, run through `migrateCampaign`
- Return result or `null` on any error

**Exported signals:**
- `campaign = signal(loadFromStorage() || createEmptyCampaign())`
- `hasExistingCampaign = signal(loadFromStorage() !== null)` -- note: call loadFromStorage ONCE, cache result, use for both
- `lastAutoSaved = signal(null)` -- timestamp for footer indicator

**Auto-save effect** (per D-13, D-15, D-16):
- Debounce 500ms using setTimeout/clearTimeout pattern
- Reads `campaign.value`, stringifies, writes to `localStorage.setItem(STORAGE_KEY, ...)`
- Updates `lastAutoSaved.value = Date.now()` after successful write
- Wraps `setItem` in try/catch for QuotaExceededError (silently fail)
- CRITICAL: The effect must NOT write to `campaign.value` (would cause infinite loop -- Pitfall 6)

**Helper functions** (immutable update pattern per Pitfall 5):
- `updateIdentity(field, value)` -- spreads campaign + identity, sets `updatedAt`
- `updateIdentityEmail(index, value)` -- clones emails array, sets index, spreads
- `addEmail()` -- appends empty string to emails array
- `removeEmail(index)` -- filters by index; if result is empty, keep `['']`
- `startNewCampaign()` -- clears localStorage key, sets campaign to empty, sets hasExistingCampaign to false

**File save/load** (per D-11, D-17, D-18, D-22):
- `saveCampaignToFile()` -- imports `fileSave` from `browser-fs-access`, creates Blob from `JSON.stringify(campaign.value, null, 2)` with type `application/json`, calls `fileSave(blob, { fileName: 'erasure-kit-campaign.json', extensions: ['.json'], description: 'ErasureKit Campaign' })`. Always pass NO handle (per D-17 -- always show picker). Catch AbortError silently.
- `loadCampaignFromFile()` -- imports `fileOpen` from `browser-fs-access`, calls `fileOpen({ mimeTypes: ['application/json'], extensions: ['.json'], description: 'ErasureKit Campaign' })`, reads text, parses JSON, runs `migrateCampaign`. If migration returns null: return `{ error: 'invalid' }`. If valid: set `campaign.value = migrated`, return `{ success: true }`. On AbortError: return `{ cancelled: true }`. On parse error: return `{ error: 'parse' }`.

**CRITICAL for IDEN-04:** The file must contain ZERO instances of `fetch`, `XMLHttpRequest`, or `navigator.sendBeacon`. browser-fs-access uses only the File System Access API and DOM elements (a download, input file) -- no network calls.
