    This is a full-screen modal (per D-01) that shows during batch sending. It has three states: sending, rate-limited, and complete.

    Props: { visible, progress, rateLimitInfo, isComplete, onAbort, onViewCampaign }
    - visible: boolean -- whether to render the modal
    - progress: { current, total, broker, sent, failed } or null -- current send progress
    - rateLimitInfo: { seconds, broker } or null -- rate limit countdown info
    - isComplete: boolean -- whether batch is done
    - onAbort: function -- called when user clicks Abort
    - onViewCampaign: function -- called when user clicks "View Campaign" after completion

    Structure:
    ```
    Fixed inset-0 z-50 bg-black/60 flex items-center justify-center
      Card: max-w-lg w-full mx-4 bg-[var(--ek-surface-alt)] rounded-xl border border-[var(--ek-border)] p-8 shadow-2xl

      IF sending (not complete, no rate limit):
        - "Sending Requests..." heading (text-xl font-semibold)
        - Progress bar: div w-full h-3 bg-[var(--ek-surface)] rounded-full overflow-hidden
          - Inner div with width: (current/total * 100)%, bg-[var(--ek-primary)], transition-all duration-300
        - Current broker name: text-sm text-[var(--ek-text-muted)] truncate mt-3
        - Stats row: flex justify-between mt-4
          - "Sent: {sent}" in text-emerald-500
          - "Failed: {failed}" in text-red-500 (only if failed > 0)
          - "Remaining: {total - current}" in text-[var(--ek-text-muted)]
        - "{current} of {total}" counter: text-sm text-center text-[var(--ek-text-muted)] mt-2
        - Abort button: mt-6 w-full h-12 border border-[var(--ek-border)] rounded-lg text-[var(--ek-text)] hover:bg-[var(--ek-surface)]
          Text: "Abort Sending"
          onClick: onAbort

      IF rate limited (per D-05):
        - Amber clock icon (inline SVG)
        - "Rate Limited" heading
        - "Resuming in {seconds}s..." with countdown (use local state decremented via setInterval)
        - "Paused on: {broker.name}" text
        - Same Abort button

      IF complete (per D-03):
        - Green checkmark icon (inline SVG)
        - "Sending Complete" heading
        - Stats: "{sent} sent, {failed} failed"
        - "View Campaign" button: w-full h-12 bg-[var(--ek-primary)] text-white rounded-lg
          onClick: onViewCampaign
    ```
