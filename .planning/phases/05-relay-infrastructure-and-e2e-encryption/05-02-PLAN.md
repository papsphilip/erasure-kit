<objective>
Create the browser-side E2E encryption module and upgrade the campaign schema to store encryption keys. The crypto module generates RSA-OAEP 2048-bit key pairs, exports them as JWK for storage in the campaign file, and implements hybrid encryption (RSA-OAEP wraps AES-256-GCM session key, AES encrypts the body). The campaign schema bumps to v3 with an `encryption` field for the key pair.

Purpose: Without this, the browser cannot encrypt email bodies before sending to the Worker relay. E2E encryption is the core privacy guarantee -- the domain owner never sees email content.
Output: `src/lib/crypto.js` with full encrypt/decrypt cycle, updated `src/lib/campaign.js` with v3 schema.
</objective>

    Constants at top of module:
    ```javascript
    const RSA_ALGORITHM = { name: 'RSA-OAEP', hash: 'SHA-256' };
    ```

    **Export `generateCampaignKeyPair()`:**
    1. Call `crypto.subtle.generateKey({ name: 'RSA-OAEP', modulusLength: 2048, publicExponent: new Uint8Array([1, 0, 1]), hash: 'SHA-256' }, true, ['encrypt', 'decrypt'])` -- `extractable: true` is required for JWK export (per D-11)
    2. Export public key: `crypto.subtle.exportKey('jwk', keyPair.publicKey)`
    3. Export private key: `crypto.subtle.exportKey('jwk', keyPair.privateKey)`
    4. Return `{ publicKeyJwk, privateKeyJwk }`

    **Export `encryptEmailBody(plaintext, publicKeyJwk)`:**
    1. Import public key from JWK: `crypto.subtle.importKey('jwk', publicKeyJwk, { name: 'RSA-OAEP', hash: 'SHA-256' }, false, ['encrypt'])`
    2. Generate random AES-256-GCM session key: `crypto.subtle.generateKey({ name: 'AES-GCM', length: 256 }, true, ['encrypt', 'decrypt'])`
    3. Generate random 12-byte IV: `crypto.getRandomValues(new Uint8Array(12))`
    4. Encrypt plaintext with AES-GCM: `crypto.subtle.encrypt({ name: 'AES-GCM', iv }, sessionKey, new TextEncoder().encode(plaintext))`
    5. Export session key as raw bytes: `crypto.subtle.exportKey('raw', sessionKey)`
    6. Wrap (encrypt) session key bytes with RSA-OAEP public key: `crypto.subtle.encrypt({ name: 'RSA-OAEP' }, publicKey, rawSessionKey)`
    7. Base64-encode all three outputs using a helper function that converts ArrayBuffer to base64 string
    8. Return `{ encryptedBody: <base64>, wrappedKey: <base64>, iv: <base64> }`

    **Export `decryptEmailBody({ encryptedBody, wrappedKey, iv }, privateKeyJwk)`:**
    1. Import private key from JWK: `crypto.subtle.importKey('jwk', privateKeyJwk, { name: 'RSA-OAEP', hash: 'SHA-256' }, false, ['decrypt'])`
    2. Base64-decode all three inputs
    3. Unwrap (decrypt) the session key with RSA-OAEP: `crypto.subtle.decrypt({ name: 'RSA-OAEP' }, privateKey, wrappedKeyBytes)`
    4. Import raw session key as AES-GCM: `crypto.subtle.importKey('raw', rawSessionKey, { name: 'AES-GCM' }, false, ['decrypt'])`
    5. Decrypt body with AES-GCM: `crypto.subtle.decrypt({ name: 'AES-GCM', iv: ivBytes }, sessionKey, ciphertextBytes)`
    6. Decode and return plaintext: `new TextDecoder().decode(plaintext)`

    **Base64 helpers (internal, not exported):**
    - `arrayBufferToBase64(buffer)` -- convert ArrayBuffer to base64 string using `btoa(String.fromCharCode(...new Uint8Array(buffer)))`
    - `base64ToArrayBuffer(base64)` -- convert base64 string back to ArrayBuffer using `atob()` + Uint8Array
