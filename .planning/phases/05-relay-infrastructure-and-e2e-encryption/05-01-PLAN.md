<objective>
Create the Cloudflare Worker project that serves as the email relay for ErasureKit. The Worker accepts encrypted email payloads via POST /send, sends them through Resend API from temporary @erasurekit.uk addresses, stores temp address -> public key mappings in Cloudflare KV, and supports DELETE /address for campaign cleanup. All responses follow the structured JSON envelope format. Rate limiting via KV protects against abuse.

Purpose: This is the backend relay that replaces mailto: links. Without it, no automated email sending is possible.
Output: A complete `worker/` directory with all source, tests, and config -- ready for deployment.
</objective>

    Export `corsHeaders()` function returning object with:

    **7. Create `worker/src/lib/validate.js`:**
    Export `validateSendPayload(body)` that checks for required fields: `to` (string, contains @), `subject` (string, non-empty), `encryptedBody` (string, non-empty), `wrappedKey` (string, non-empty), `iv` (string, non-empty), `tempAddress` (string, 8 chars alphanumeric). Returns `{ valid: true }` or `{ valid: false, field: "to", reason: "..." }`.

    Export `validateDeletePayload(slug)` that checks slug is a non-empty string of 8 alphanumeric chars. Returns `{ valid: true }` or `{ valid: false, reason: "..." }`.

    **8. Create `worker/src/lib/rate-limit.js`:**
    Export `checkRateLimit(env, ip, limit = 10, windowSec = 60)`. Implementation:
    - Key format: `rate:${ip}:${Math.floor(Date.now() / (windowSec * 1000))}` (IP + minute-bucket to avoid KV 1-write/sec per key limit -- per Pitfall 4 from RESEARCH.md)
    - Read current count from KV, if >= limit return `{ allowed: false, remaining: 0, retryAfter: windowSec }`
    - Otherwise increment and write with `expirationTtl: windowSec * 2` (double window for safety)
    - Return `{ allowed: true, remaining: limit - current - 1 }`

    **9. Create `worker/src/lib/resend.js`:**
    Constants at top:
    ```javascript
    const RESEND_API_URL = 'https://api.resend.com/emails';
    const USER_AGENT = 'ErasureKit-Worker/1.0';
    const DOMAIN = 'erasurekit.uk';
    ```

    Export `sendEmail(env, { from, to, subject, html, replyTo })`:
    - Calls `fetch(RESEND_API_URL, { method: 'POST', headers: { Authorization: Bearer ${env.RESEND_API_KEY}, Content-Type: application/json, User-Agent: USER_AGENT }, body: JSON.stringify({ from, to: [to], subject, html, reply_to: replyTo }) })`
    - If response.ok: return `{ success: true, emailId: data.id }`
    - If response.status === 429: return `{ success: false, code: 'RATE_LIMITED', retryAfter: response.headers.get('Retry-After') || '60' }`
    - Otherwise: return `{ success: false, code: 'RESEND_FAILED', statusCode: response.status, message: data.message || 'Unknown Resend error' }`

    **10. Create `worker/src/routes/send.js`:**
    Export `handleSend(request, env)`:
    1. Parse JSON body, catch parse errors -> INVALID_PAYLOAD 400
    2. Validate with `validateSendPayload()` -> INVALID_PAYLOAD 400 on failure
    3. Check rate limit via `checkRateLimit(env, request.headers.get('CF-Connecting-IP'))` -> RATE_LIMITED 429 with Retry-After header on failure
    4. Construct sender: `${body.tempAddress}@erasurekit.uk`
    5. Register temp address in KV: key `addr:${body.tempAddress}`, value `JSON.stringify({ publicKey: body.publicKey, createdAt: new Date().toISOString() })`, TTL 7776000 seconds (90 days, per D-08)
    6. Call `sendEmail(env, { from: sender, to: body.to, subject: body.subject, html: body.encryptedBody, replyTo: sender })` (per D-14: Reply-To = same temp address)
    7. On success: return `{ success: true, data: { emailId, tempAddress: sender } }` with 200
    8. On RATE_LIMITED from Resend: return `{ success: false, error: { code: 'RATE_LIMITED', message: '...' } }` with 429
    9. On RESEND_FAILED: return `{ success: false, error: { code: 'RESEND_FAILED', message: '...' } }` with 502

    **11. Create `worker/src/routes/address.js`:**
    Export `handleDeleteAddress(request, env)`:
    1. Parse slug from URL search params: `new URL(request.url).searchParams.get('slug')`
    2. Validate slug with `validateDeletePayload(slug)` -> INVALID_PAYLOAD 400 on failure
    3. Delete from KV: `env.KV.delete('addr:' + slug)`
    4. Return `{ success: true, data: { deleted: slug } }` with 200

    **12. Create `worker/src/index.js`:**
    Import `handleSend`, `handleDeleteAddress`, `handleCORS`, `corsHeaders`, `checkRateLimit`.

    Export default object with `fetch(request, env, ctx)`:
    1. If `request.method === 'OPTIONS'` -> return `handleCORS()`
    2. Parse URL pathname
    3. If `/send` + POST -> `handleSend(request, env)`
    4. If `/address` + DELETE -> `handleDeleteAddress(request, env)`
    5. Otherwise -> `{ success: false, error: { code: 'NOT_FOUND', message: 'Unknown endpoint' } }` with 404
    6. All responses include CORS headers via a `jsonResponse(body, status, extraHeaders)` helper that merges `corsHeaders()` into every response

    **13. Create test files:**
    - `worker/tests/send.test.js`: Tests for POST /send (valid payload, missing fields, Resend errors, CORS headers, response format, KV registration with TTL)
    - `worker/tests/address.test.js`: Tests for DELETE /address (valid slug, missing slug, KV deletion)
    - `worker/tests/rate-limit.test.js`: Tests for rate limiter (under limit, over limit, minute-bucket key pattern)

    Tests use `@cloudflare/vitest-pool-workers` which provides `env` bindings (including KV) via Miniflare. Mock the Resend API fetch by intercepting outgoing requests in the test.
