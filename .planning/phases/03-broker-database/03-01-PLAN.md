# Phase 3 Plan 1: Comprehensive Broker Database and Selection UI

## Objective

Compile 100+ data broker entries into brokers.json from known open-source lists, add broker selection helpers to the campaign state, and build the full Brokers page with search, filter, sort, expand, select/deselect, and Continue button.

## Context

- @.planning/phases/03-broker-database/03-CONTEXT.md (decisions D-01 through D-20)

- @src/lib/brokers-loader.js (loads brokers.json)
- @src/pages/Brokers.js (placeholder to replace)

## Tasks

### Task 1: Compile comprehensive brokers.json
type="auto"

Compile 100+ data broker entries into `public/brokers.json`. Each entry must follow the schema from D-18:
```json
{
  "id": "slug-from-name",
  "name": "Broker Name",
  "email": "privacy@broker.com",
  "region": "EU/EEA" | "UK" | "US" | "Other",
  "category": "Data Broker" | "Credit Bureau" | "People Search" | "Advertising/Adtech" | "Analytics" | "Social Media" | "Telecom" | "Other",
  "privacyPortalUrl": "https://...",
  "legalFramework": "GDPR" | "UK-GDPR" | "CCPA" | "Other",
  "tempEmailAccepted": true | false | null,
  "notes": "Optional notes"
}
```

Sources: yaelwrites/BADBOOL, JustVanish, datarequests.org, Vermont/California registries, The Markup dataset. Deduplicate by domain/name. All 4 regions and 6-8 categories must be represented.

**Done criteria:** brokers.json has 100+ entries, all with valid schema fields, no duplicate IDs.

### Task 2: Add broker selection helpers to campaign state
type="auto"

Add to `src/lib/campaign.js`:
- `toggleBrokerSelection(brokerId)` - toggle a broker ID in/out of selections
- `selectBrokers(brokerIds)` - add multiple broker IDs to selections
- `deselectAllBrokers()` - clear all selections
- `isBrokerSelected(brokerId)` - check if a broker is selected

Campaign schema update: `campaign.brokers` gains `selected: []` (array of broker ID strings, per D-15).

**Done criteria:** Helpers work correctly, campaign auto-save captures broker selections.

### Task 3: Build Brokers page UI
type="auto"

Replace the placeholder `src/pages/Brokers.js` with the full broker selection UI per decisions D-01 through D-16:

- Sticky toolbar with search input + Region dropdown + Category dropdown (D-06, D-07)
- Filter-as-you-type search by name (D-08)
- AND between filter types, single-select dropdowns (D-09)
- "Showing N of M brokers | X selected (x)" result count (D-10)
- "x Clear filters" link when any filter active (D-11)
- Empty search state with "No brokers match" message (D-12)
- Compact table: checkbox, name, email (truncated), region, category (D-01)
- Sortable column headers (name, region, category) (D-01)
- Expandable rows showing full details on click (D-03)
- Temp-email-blocked warning icon (D-04)
- Selected row accent tint + checked checkbox (D-05)
- Select All checkbox in header + "Select all N visible" button (D-13)
- "X selected (x)" deselect all (D-14)
- Continue to Send button, disabled until 1+ selected (D-16)
- Container: max-w-4xl centered (D-02)

**Done criteria:** User can search, filter, sort, expand, select/deselect brokers. Selections persist in campaign. Continue navigates to send step.
